About CareerConnect

A full-stack job portal built with Java and Spring Boot.

Features

  • Role-based access for Admins, Employers and Job Seekers
  • Secure sign-up and login with BCrypt password hashing (Spring Security)
  • Job search by keyword, location and job type with pagination
  • Employers post, edit, close and delete jobs and move applicants through a hiring pipeline
  • Candidates apply with a cover letter and track application status
  • Admin dashboard with platform statistics, user blocking and job moderation
  • REST API (JSON) with HTTP Basic auth, validation and consistent error responses
